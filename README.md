# SREX ESP32-C6 Matter-over-Thread Tuya Lock Bridge

Target: ESP32-C6 Super Mini, 4 MB flash.

This project ports the proven Tuya UART lock bridge to a native Matter Door Lock endpoint over Thread.

## Wiring

- Lock MCU TX -> ESP32-C6 GPIO6 (RX)
- Lock MCU RX <- ESP32-C6 GPIO7 (TX)
- Lock GND <-> ESP32-C6 GND
- Power the C6 from USB during development.
- Do not tie the lock 3.3 V rail to the C6 3V3 rail while USB powers the C6.

The project deliberately uses UART1 on GPIO6/GPIO7 so the board's native USB connection remains available for flashing and logs.

## What is implemented

- Matter Door Lock device over Thread
- BLE commissioning + OpenThread networking
- Tuya wake sequence with fixed 0x55AA sequence
- CMD00 / CMD05 / CMD23 acknowledgements
- CMD24 time response
- CMD04 acknowledgement processing
- DP47 and DP57 physical lock-state tracking
- DP48 remote-key provisioning
- DP49 remote unlock
- DP57 remote lock
- Physical state reports are pushed back into Matter LockState

## Build: easiest method

Install Docker, then from this folder run:

```bash
./build_with_docker.sh
```

The official `espressif/esp-matter:latest` image contains ESP-IDF and ESP-Matter.

Output:

```text
release/srex-c6-matter-thread-lock-merged.bin
```

## ESP Launchpad

Open Espressif ESP Launchpad, choose **DIY**, connect the ESP32-C6, select ESP32-C6, then add:

```text
srex-c6-matter-thread-lock-merged.bin
address: 0x0
```

Erase flash for the first installation, then flash.

Launchpad also supports multiple binaries. If you prefer that route, use the addresses in `release/flash_args` generated by the build. Do not guess offsets.

## GitHub Actions build

The included workflow builds the firmware using Espressif's official Docker image. Push this project to GitHub and run:

**Actions -> Build ESP32-C6 Matter Thread Lock -> Run workflow**

Download the `srex-c6-matter-thread-lock-launchpad` artifact and flash the merged `.bin` at `0x0` in ESP Launchpad.

## Matter commissioning

After flashing, connect to the USB serial console. The Matter stack prints commissioning information during boot. Add the device to Home Assistant through its Matter integration and an existing Thread Border Router.

## Factory reset

The CHIP shell is enabled. Through the serial console, use the ESP-Matter factory-reset command if you need to clear Matter fabrics and recommission.

## Security note

The DP48/DP49 UART test key is currently fixed in `main/tuya_lock_bridge.cpp` to preserve the behavior of the working V4 prototype. For a deployed product, replace this with a randomly generated key stored in encrypted NVS and provision it to the lock.

## Pin change

If your exact Super Mini revision requires different pins, edit:

```cpp
static constexpr gpio_num_t LOCK_RX_GPIO = GPIO_NUM_6;
static constexpr gpio_num_t LOCK_TX_GPIO = GPIO_NUM_7;
```

in `main/tuya_lock_bridge.cpp` and rebuild.
